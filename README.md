# Original Gear Runner V1.0

Однофайловая мобильная web-версия игры.

## Что внутри
- полноценный цикл забега: бой → победа → добыча → продать/надеть → следующая волна;
- 5 слотов экипировки;
- 4 редкости;
- сравнение силы предметов;
- при замене экипировки старый предмет автоматически продаётся;
- уровни, XP, монеты и постоянные улучшения;
- 3 локации, открываемые по уровню;
- волны и усложнение врагов;
- лечение во время забега;
- локальное сохранение в браузере;
- управление кнопками и свайпами;
- все визуальные элементы находятся прямо в index.html.

## GitHub Pages
Загрузите `index.html` в корень репозитория. README.md не обязателен для работы игры.
