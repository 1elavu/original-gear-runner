# Original Gear Runner V2.1

Системная прогрессия:
- 5 PvP-лиг и цели по трофеям;
- ежедневные задания;
- 7-дневная серия входов с наградами;
- достижения;
- награды за выполнение целей;
- сохранены бои, активные навыки, экипировка, инвентарь, герои, магазин и PvP.

Для GitHub Pages достаточно заменить `index.html`.
