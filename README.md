# Original Gear Runner V1.2

Крупное обновление:
- нижняя навигация: Забег / PvP / Герои / Магазин;
- асинхронный PvP с подбором соперника по близким кубкам;
- PvP может использовать ботов/снимки соперников, без требования одновременного онлайна;
- кубки, победы/поражения и награды;
- 3 героя с разными пассивными способностями;
- магазин за внутриигровые монеты;
- ежедневный бесплатный подарок;
- подготовлена витрина премиум-покупок. Реальные платежи за рубли/доллары подключаются только на нативном этапе через официальные платежи App Store/Google Play.
- базовый игровой цикл V1.1 сохранён.

Для GitHub Pages достаточно заменить index.html.
